# CTF（旗取り）仕様

3v3 のラウンド制。**相手の旗を持ち帰ってリスポーンを封じ、相手チームを全滅させた方がラウンドの勝ち。2 ラウンド先取で試合の勝ち。**

## ルール

### 旗
| 項目 | 内容 | 初期値 |
|---|---|---|
| 拾う | 敵チームの旗（台にある／落ちている）に触れる | — |
| 持ち帰り | 敵の旗を持って**自陣の旗台**に触れる。ただし**自分の旗が台にあるときだけ**（自分の旗が持ち帰られて消えている場合は条件なし） | — |
| 落とす | 運び手が死ぬと、その場（真下の地面）に落ちる | — |
| 回収 | 落ちた旗に味方が触れると即座に台へ戻る | — |
| 自動で戻る | 落ちてから誰も触らなければ台へ戻る | 15 秒 |
| 即座に戻る | 運び手の切断・奈落（KillZ）落下 | — |

### 運び手の制限
- 移動速度ダウン（`MoveSpeedMultiplier` ×0.85）
- `Ability.Type.Skill` を持つ能力は使用不可（ブリンク・シールド・グラップル）。拾った瞬間、使用中のものも中断する
- 武器・ガジェットは使える

### 持ち帰られたとき
- 旗を持ち帰られたチームは、**そのラウンド中リスポーン不可**になる
- 持ち帰られた旗は消える。そのチームは「自分の旗が台にある」条件なしで相手の旗を持ち帰れる（成功すれば相手もリスポーン不可）

### ラウンドの勝敗
- 相手チームが全滅（全員死亡かつリスポーン不可）したら勝ち
- 試合は **2 ラウンド先取**

### 制限時間切れ
| 時間切れの時点 | 結果 |
|---|---|
| どちらの旗も持ち帰られていない | **デスマッチ**へ移行。両チームの旗が消え、全員リスポーン不可。相手を全滅させた方の勝ち |
| 片方の旗だけ持ち帰られている | **旗が残っているチームのラウンド勝利** |
| 両方の旗が持ち帰られている | 両チームともすでにリスポーン不可なので、そのまま全滅させた方の勝ち |

リスポーン不可で死んだプレイヤーは、当面は死亡地点のカメラのまま（味方の観戦は後回し）。

### ラウンドの流れ
```
WaitingToStart → PreRound(カウントダウン・移動不可) → InRound → (時間切れ → Deathmatch) → RoundEnd(結果表示) → 次の PreRound … → MatchEnd
```
| 項目 | 初期値 |
|---|---|
| ラウンド開始前のカウントダウン | 3 秒 |
| 1 ラウンドの制限時間 | 180 秒 |
| ラウンド終了後の結果表示 | 5 秒 |
| 試合に勝つのに必要なラウンド数 | 2 |

ラウンドのリセット: 全 Pawn を破棄 → HP・GE を初期化 → 旗を台に戻す → 設置物（スモーク・ドームシールド・グレネード）を消す → 全員を自チームのスポーン地点から出し直す。

## クラス構成

| クラス | 役割 |
|---|---|
| `ASavaFlag` | 旗本体。状態（`AtBase` / `Carried` / `Dropped` / `Removed`）と運び手を複製。当たり判定はサーバーのみ |
| `ASavaFlagBase` | 各チームの旗台。レベルに置く。サーバーで自チームの旗をスポーンし、持ち帰りの判定エリアになる |
| `ASavaGameState` | ラウンドの段階・残り時間・ラウンド取得数・チームごとのリスポーン可否を全員に配る |
| `ASavaCTFGameMode` | `AsavaGameMode` を継承。ラウンド進行・勝敗判定・チーム別スポーン |
| `ASavaTeamPlayerStart` | `TeamId` を持つ PlayerStart。`ChoosePlayerStart` で自チームのものを選ぶ |
| `USavaGE_CarryingFlag` | 運び手に付ける無期限 GE（C++）。タグ `State.CarryingFlag` 付与＋移動速度ダウン |
| `USavaGE_RoundFrozen` | カウントダウン中に付ける無期限 GE（C++）。タグ `State.RoundFrozen` 付与＋移動速度 0。ジャンプ・全能力も使えない |

- スキル封じは `USavaGameplayAbility` の発動判定で「`Ability.Type.Skill` を持ち、所有者に `State.CarryingFlag` があれば発動不可」とする（BP でタグを付けた能力にも効く）
- 運び手が死ぬと `AsavaCharacter::HandleDeath` から旗に通知して落とす。死亡時に全 GE が外れるので制限も自動で解除される
- 死亡のたびに GameMode が全滅を判定する（リスポーン不可のチームの生存者が 0 人ならラウンド終了）

## マップのセットアップ手順
1. Content Browser で `SavaCTFGameMode` を親に Blueprint を作る（例: `BP_CTFGameMode`）。必要なら `BP_FirstPersonGameMode` と同じ HUD などを設定する
   - Game State Class は自動で `SavaGameState` になる。変えないこと
   - 試合を始める人数は `Min Players To Start`（テスト中は 1、本番は 6）
2. CTF 用マップの World Settings → GameMode Override に `BP_CTFGameMode` を入れる
3. `SavaFlagBase` を 2 個置き、`Team Id` を 0 と 1 にする（旗はプレイ開始時に自動で出る）
4. `SavaTeamPlayerStart` を各チーム 3 個以上置き、`Team Id` を設定する（普通の PlayerStart は使われない）
5. PIE で確認する（Net Mode: Play As Listen Server、プレイヤー 2 人など）。画面左上に試合の状態が黄色の文字で出る

旗の見た目を変えたいときは `SavaFlag` を親に BP を作り、メッシュを差し替えて `SavaFlagBase` の `Flag Class` に入れる。
布のマテリアルにベクターパラメーター `Color` があると、チームの色（`Team Colors`）が入る。

## 実装メモ
- 奈落（KillZ）に落ちたキャラクターは死亡扱いになる（`AsavaCharacter::FellOutOfWorld`）。以前は体が消えるだけでリスポーンされなかった
- 運び手の判定（死亡・切断・持ち帰り）と拾う判定は、サーバーで旗の Tick ごとに行う
- テスト: `Sava.CTF.*`（旗の効果・カウントダウンの効果・スキル封じ・GameState）

## 今回の範囲外（後回し）
- HUD（スコア・旗の位置・残り時間）、ラウンド／試合終了画面、旗の見た目
  - 値は `ASavaGameState` に持たせるので、後から BP の Widget で表示できる。動作確認用にはデバッグ表示のみ付ける
- リスポーン不可時の味方観戦
